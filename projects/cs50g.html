Harvard CS50 Game Dev

Harvard's CS50 Introduction to Game Development. Each assignment meant taking a base game and adding new features, mechanics or systems, first in Lua with LÖVE 2D, then in C# with Unity. The course walks through classic genres and how their architecture works.

Type

Assignments

Each project extends a classic: Flappy Bird, Match-3, Angry Birds-style physics, a Zelda-like dungeon crawler and more. The work covered state machines, tile maps, physics, procedural generation and moving from Lua to C# in Unity.
