Interaction System

A small, reusable interaction framework for Unreal projects. The player owns one component; anything in the world becomes interactable by implementing a single interface. It was built by following a tutorial and then kept as the base for my later projects.

Type
Tutorial project
Engine

Gameplay programmer
01

Trace + interface

UInteractionComponent traces from the owner's eye viewpoint along the camera direction. If it hits an actor implementing IObjectInterface, it calls Interact() on it. The player never casts to concrete types, so doors, pickups and levers all work without changes to the player.

The trace distance and a debug-line toggle are exposed as properties, which makes it easy to tune per project.

In-game
InteractionComponent.cppC++
#include "Components/InteractionComponent.h"
#include "Interfaces/ObjectInterface.h"
#include "GameFramework/Actor.h"
#include "Engine/World.h"
#include "DrawDebugHelpers.h"

UInteractionComponent::UInteractionComponent()
{
    PrimaryComponentTick.bCanEverTick = true;
}

void UInteractionComponent::BeginPlay()
{
    Super::BeginPlay();
}

void UInteractionComponent::TickComponent(float DeltaTime, ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction)
{
    Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
}

void UInteractionComponent::Interact()
{
    AActor* InteractableActor = GetInteractableActor();
    if (InteractableActor && InteractableActor->Implements<UObjectInterface>())
    {
        IObjectInterface* Interface = Cast<IObjectInterface>(InteractableActor);
        if (Interface)
        {
            Interface->Interact();
        }
    }
}

AActor* UInteractionComponent::GetInteractableActor() const
{
    AActor* Owner = GetOwner();
    if (!Owner) return nullptr;

    FVector Start;
    FRotator CameraRotation;
    GetOwner()->GetActorEyesViewPoint(Start, CameraRotation);
    FVector End = Start + (CameraRotation.Vector() * InteractionDistance);

    FHitResult HitResult;
    FCollisionQueryParams Params;
    Params.AddIgnoredActor(GetOwner());

    if (DrawLine)
    {
        DrawDebugLine(GetWorld(), Start, End, FColor::Red, false, 2000.0f);
    }

    if (GetWorld()->LineTraceSingleByChannel(HitResult, Start, End, ECC_Visibility, Params))
    {
        if (HitResult.GetActor() && HitResult.GetActor()->Implements<UObjectInterface>())
        {
            return HitResult.GetActor();
        }
    }

    return nullptr;
}

What I learned

Interfaces are what make this reusable: the component only knows about the contract, not the objects. That idea carried straight into the Souls-like, where enemies, the player and the lock-on system all communicate through interfaces.
